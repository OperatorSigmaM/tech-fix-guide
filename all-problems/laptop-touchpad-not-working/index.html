Laptop Touchpad Not Working? 14 Ways to Fix Trackpad Issues

📅 Updated: January 2025 ⏱️ 16 min read Easy

🎯 Quick Summary

Problem: Laptop touchpad cursor not moving, clicking not working, gestures disabled, or touchpad completely unresponsive.

Most common causes: Touchpad disabled via keyboard shortcut (35%), driver issues (25%), external mouse disabling touchpad (20%), incorrect settings (15%), hardware failure (5%)

Quick fix (works 75% of time): Press Fn+F7 (or touchpad key) → Check touchpad settings → Update drivers → Restart laptop → Unplug external mouse

Time needed: 5-20 minutes depending on solution

First: Identify Your Touchpad Problem

Different symptoms require different solutions:

🔴 Cursor not moving at all:

  • Touchpad completely dead, no cursor movement
  • Cursor visible but frozen in one spot
  • No response to finger movement
  • Likely cause: Touchpad disabled (Fn key), driver issue, hardware failure

🔴 Cursor moving but clicking not working:

  • Can move cursor around screen
  • Left-click, right-click doesn't respond
  • Tap-to-click doesn't work
  • Likely cause: Tap-to-click disabled, touchpad buttons faulty, settings misconfigured

🔴 Gestures not working (two-finger scroll, pinch-to-zoom):

  • Basic cursor movement works
  • Two-finger scrolling doesn't work
  • Pinch-to-zoom, three-finger swipe disabled
  • Likely cause: Precision touchpad gestures disabled in settings

🔴 Touchpad works but cursor jumps/erratic:

  • Cursor jumps randomly across screen
  • Moves by itself while typing
  • Very jittery, imprecise movement
  • Likely cause: Palm detection off, touchpad sensitivity too high, driver issue

🔴 Touchpad disabled when external mouse connected:

  • Works fine when mouse unplugged
  • Stops working when mouse plugged in
  • Likely cause: "Disable touchpad when mouse connected" setting enabled

🔴 Touchpad partially working (some areas dead):

  • Top/bottom half of touchpad doesn't respond
  • Clicking works but movement doesn't (or vice versa)
  • Likely cause: Hardware damage, wear and tear, liquid damage

🔴 Stopped working after Windows update:

  • Touchpad worked fine before update
  • Completely stopped after Windows Update installed
  • Likely cause: Driver incompatibility, Windows overwriting touchpad driver
💡 Touchpad Types:
• Precision Touchpad (Windows 10/11): Advanced gestures, best drivers. Found in newer laptops (Dell XPS, HP Spectre, Lenovo Yoga, Surface).
• Synaptics: Most common in older laptops. Separate driver software.
• ELAN: Budget laptops. Basic functionality.
• Alps: Older laptops, less common now.
• Mac Trackpad: Best-in-class, glass surface, Force Touch. Different troubleshooting (macOS specific).

Check Device Manager → Mice and other pointing devices to see your touchpad type.

Quick Fixes (Start Here - 75% Success Rate)

1 Check Touchpad Function Key (Fn Key) Success: 50%

When to try: Touchpad suddenly stopped working, or accidentally pressed keyboard key.

Why it works: #1 cause of touchpad issues. Most laptops have keyboard shortcut to enable/disable touchpad.

Common touchpad keyboard shortcuts:

  • Fn + F7 (Dell, Lenovo)
  • Fn + F5 (Toshiba, some Dell)
  • Fn + F6 (Samsung)
  • Fn + F9 (HP, Asus)
  • Fn + F8 (Acer)
  • Look for touchpad icon on F-keys (rectangular pad with finger icon)

How to re-enable touchpad:

  1. Look at F1-F12 row for touchpad icon (usually looks like 📱 or two fingers)
  2. Press Fn + that F-key
  3. On-screen notification should appear: "Touchpad Enabled" or "Touchpad Disabled"
  4. If already enabled, press again to toggle off then on
  5. Test cursor movement

Some laptops have dedicated touchpad button:

  • Small LED button on touchpad itself (top-left or top-right corner)
  • Press once to toggle touchpad on/off
  • LED lights up when touchpad disabled
💡 Why touchpad gets disabled accidentally: Easy to press Fn+F7/F9 while gaming or typing quickly. Very common! Always try this FIRST before troubleshooting drivers/settings.

2 Restart Laptop Success: 30%

When to try: Touchpad stopped working suddenly, or after installing software.

Why it works: Clears driver glitches, resets touchpad service, reinitializes hardware.

Proper restart procedure:

  1. Save all work
  2. Start Menu → Power → Restart (NOT shut down)
  3. Wait for complete reboot
  4. Test touchpad immediately after login

If touchpad completely dead (can't navigate to restart):

  • Use keyboard navigation:
    • Press Windows key
    • Arrow keys to navigate
    • Enter to select
    • Or: Ctrl+Alt+Delete → Tab to Restart → Enter
  • Or plug in external USB mouse temporarily
💡 Restart vs Shut Down: Full restart better than shut down → power on. Windows Fast Startup (hybrid shutdown) doesn't fully clear drivers. Restart forces complete driver reload.

3 Unplug External Mouse Success: 35%

When to try: Touchpad works when mouse unplugged, stops when mouse connected.

Why it works: Many laptops auto-disable touchpad when external mouse detected (prevent accidental cursor movement).

Quick test:

  1. Unplug all external mice (USB, wireless receiver)
  2. Wait 5 seconds
  3. Test touchpad
  4. If works → setting is disabling touchpad when mouse connected

Change this behavior (allow both touchpad + mouse):

  • Windows 11:
    • Settings → Bluetooth & devices → Touchpad
    • Look for "Leave touchpad on when mouse is connected"
    • Toggle ON
  • Windows 10:
    • Settings → Devices → Touchpad
    • Uncheck "Leave touchpad on when a mouse is connected"
  • Synaptics/ELAN software:
    • Control Panel → Mouse → Device Settings tab
    • Disable "Disable internal pointing device when external USB pointing device is attached"

4 Check Touchpad Enabled in Settings Success: 40%

When to try: Touchpad completely unresponsive, or disabled in Windows settings.

Windows 11 - Enable touchpad:

  1. Settings → Bluetooth & devices → Touchpad
  2. Make sure main toggle at top is ON
  3. Check "Touchpad" switch is enabled
  4. Scroll down, ensure all gesture settings enabled

Windows 10 - Enable touchpad:

  1. Settings → Devices → Touchpad
  2. Touchpad toggle should be ON
  3. If toggle greyed out, see Solution #5 (driver issue)

Control Panel - Mouse Properties (classic method):

  1. Control Panel → Mouse
  2. Look for tabs: "Device Settings" or touchpad brand name (Synaptics, ELAN)
  3. Select touchpad device
  4. Click "Enable" button
  5. Apply → OK

If touchpad not listed in Settings:

  • Driver missing or not installed
  • See Solution #5 (Update drivers)
  • Or Solution #6 (Device Manager)

5 Update or Reinstall Touchpad Drivers Success: 45%

When to try: Touchpad stopped working after Windows update, or Device Manager shows errors.

Why it works: Outdated/corrupted drivers = #1 software cause of touchpad failures.

Windows - Update touchpad driver:

  1. Right-click Start → Device Manager
  2. Expand "Mice and other pointing devices"
  3. Look for touchpad:
    • "HID-compliant touch pad"
    • "Synaptics TouchPad"
    • "ELAN Touchpad"
    • "Precision Touchpad"
  4. Right-click touchpad → "Update driver"
  5. Choose "Search automatically for drivers"
  6. Install if found
  7. Restart laptop

Download driver from manufacturer (better method):

  1. Identify laptop model (check bottom sticker or Settings → System → About)
  2. Visit manufacturer website:
    • Dell: dell.com/support → Enter service tag → Drivers
    • HP: support.hp.com → Download drivers → Enter product name
    • Lenovo: support.lenovo.com → Detect product → Drivers
    • Asus: asus.com/support → Find your model → Drivers
  3. Download "Touchpad Driver" or "Mouse Driver"
  4. Run installer
  5. Restart

Reinstall touchpad driver (if update doesn't work):

  1. Device Manager → Mice and other pointing devices
  2. Right-click touchpad → "Uninstall device"
  3. Check "Delete the driver software for this device" (if option appears)
  4. Click "Uninstall"
  5. Restart laptop
  6. Windows automatically reinstalls driver on boot
  7. Or manually install manufacturer driver
⚠️ Windows Update breaking touchpad drivers: Major Windows feature updates (twice yearly) sometimes overwrite touchpad drivers with generic Microsoft drivers that don't support gestures. After big Windows updates, always reinstall touchpad driver from laptop manufacturer website.

6 Enable Touchpad in Device Manager Success: 40%

When to try: Touchpad disabled in Device Manager, or shows error icon.

Check Device Manager status:

  1. Right-click Start → Device Manager
  2. Expand "Mice and other pointing devices"
  3. Look for your touchpad

Touchpad status indicators:

  • Normal icon: Enabled and working
  • Down arrow ⬇: Disabled → Right-click → "Enable device"
  • Yellow triangle ⚠: Driver error → Update or reinstall driver
  • Red X: Device disabled or hardware failure
  • Not listed: Driver not installed or hardware not detected

If touchpad disabled (down arrow):

  1. Right-click touchpad device
  2. Select "Enable device"
  3. Wait few seconds
  4. Test touchpad

If touchpad has yellow triangle:

  1. Right-click → Properties
  2. Device status shows error code
  3. Common codes:
    • Code 10: "Device cannot start" → Reinstall driver
    • Code 28: "Drivers not installed" → Install touchpad driver
    • Code 43: "Windows has stopped this device" → Hardware or driver issue
  4. Try: Update driver or reinstall

Settings & Configuration Solutions

7 Enable Tap-to-Click Success: 35%

When to try: Cursor moves but clicking doesn't work, or tapping touchpad does nothing.

Windows 11 - Enable tap-to-click:

  1. Settings → Bluetooth & devices → Touchpad
  2. Scroll to "Taps"
  3. Enable these options:
    • "Tap with a single finger to single-click" → ON
    • "Tap with two fingers to right-click" → ON
    • "Tap twice and drag to multi-select" → ON (if desired)
  4. Test tapping on touchpad

Windows 10 - Enable tap-to-click:

  1. Settings → Devices → Touchpad
  2. Under "Taps": Change to "Medium sensitivity" or "Most sensitive"
  3. Make sure tap sensitivity not set to "No taps"

Advanced touchpad settings (Synaptics/ELAN):

  1. Control Panel → Mouse
  2. Click touchpad tab (Synaptics, ELAN, or Device Settings)
  3. Settings button
  4. Look for "Tapping" section
  5. Enable "Tap to click"
  6. Adjust tap sensitivity if needed

Physical clicking not working:

  • If tap-to-click works but physical click doesn't:
  • Touchpad buttons may be broken (hardware issue)
  • Use tap-to-click as workaround
  • Or see Solution #13 (hardware repair)

8 Enable Touchpad Gestures Success: 30%

When to try: Two-finger scroll, pinch-to-zoom, or swipe gestures not working.

Windows 11 - Enable gestures:

  1. Settings → Bluetooth & devices → Touchpad
  2. Scroll to "Three-finger gestures" and "Four-finger gestures"
  3. Enable desired gestures:
    • Two-finger scroll: Under "Scroll and zoom" → Enable
    • Pinch to zoom: Under "Scroll and zoom" → Enable
    • Three-finger swipe: Set to "Switch apps" or "Show desktop"
    • Four-finger swipe: Set to "Switch desktops"

Windows 10 - Enable gestures:

  1. Settings → Devices → Touchpad
  2. Scroll down to gesture sections
  3. Configure each gesture type
  4. Make sure "Scrolling direction" set to preference

Precision Touchpad vs Legacy:

  • Precision Touchpad (Windows 10/11): Full gesture support built into Windows, no extra software needed
  • Legacy touchpad (Synaptics/ELAN): Gestures configured in manufacturer software
    • Open Synaptics/ELAN control panel
    • Enable gestures in software
    • Some old touchpads don't support multi-touch gestures at all

Test gestures:

  • Two-finger scroll: Place two fingers on touchpad, move up/down
  • Pinch-to-zoom: Two fingers together, move apart (zoom in) or together (zoom out)
  • Three-finger swipe: Three fingers left/right to switch apps

9 Adjust Touchpad Sensitivity & Palm Rejection Success: 25%

When to try: Cursor jumping erratically, touchpad too sensitive, or activates while typing.

Windows 11 - Adjust sensitivity:

  1. Settings → Bluetooth & devices → Touchpad
  2. Touchpad sensitivity: Change from "Most sensitive" to "Medium" or "Low"
  3. Test cursor movement
  4. Adjust until comfortable

Enable palm rejection (prevent accidental touches while typing):

  • Windows doesn't have separate palm rejection toggle
  • Built into Precision Touchpad automatically
  • For legacy touchpads:
    • Control Panel → Mouse → Touchpad tab → Settings
    • Look for "Palm Check" or "Palm Rejection"
    • Enable and adjust sensitivity

Delay before touchpad activates after typing:

  • Synaptics software: Settings → "Delay before touchpad works after typing"
  • Set to 1-2 seconds
  • Prevents accidental cursor jumps while typing

Cursor speed adjustment:

  1. Settings → Bluetooth & devices → Mouse
  2. Or: Control Panel → Mouse → Pointer Options
  3. Adjust "Select a pointer speed" slider
  4. Uncheck "Enhance pointer precision" if cursor feels weird

10 Disable Touchpad Delay / Enhance Pointer Precision Success: 20%

When to try: Touchpad feels laggy, cursor moves after you stop moving finger, or acceleration feels off.

Disable pointer precision (acceleration):

  1. Control Panel → Mouse → Pointer Options tab
  2. UNCHECK "Enhance pointer precision"
  3. This removes Windows mouse acceleration
  4. Cursor movement becomes 1:1 with finger movement
  5. Apply → OK

Reduce touchpad input lag:

  • Update touchpad driver to latest version (reduces lag)
  • Close background apps using CPU (high CPU = input lag)
  • Disable any touchpad software running in background if not needed

For gamers (touchpad lag):

  • Touchpads have inherent lag (10-30ms) vs gaming mice (1-5ms)
  • Can't be eliminated completely
  • Use external mouse for gaming

Advanced Solutions & Hardware Fixes

11 Check BIOS Settings Success: 15%

When to try: Touchpad not detected anywhere (Device Manager, BIOS), or corporate laptop with restricted settings.

Access BIOS:

  1. Restart laptop
  2. Immediately press BIOS key repeatedly:
    • Dell: F2
    • HP: F10 or Esc
    • Lenovo: F1 or F2
    • Asus: F2 or Delete
    • Acer: F2
  3. Enter BIOS/UEFI setup

Find touchpad setting in BIOS:

  • Navigate with arrow keys
  • Look in:
    • Advanced tab
    • Device Configuration
    • System Configuration
    • Integrated Devices
  • Setting may be called:
    • "Internal Pointing Device"
    • "Touchpad"
    • "Pointing Device"

Enable touchpad in BIOS:

  1. Find touchpad setting
  2. Change from "Disabled" to "Enabled"
  3. Press F10 to "Save and Exit"
  4. Laptop restarts
  5. Test touchpad
⚠️ BIOS warning: Only change settings you understand. Wrong BIOS settings can prevent laptop from booting. If unsure, load "BIOS defaults" (usually F9).

12 Clean Touchpad Surface Success: 20%

When to try: Touchpad erratic, cursor jumps, or feels "sticky" to touch.

What you need:

  • Microfiber cloth
  • Isopropyl alcohol 70% (rubbing alcohol)
  • Cotton swabs (for edges)

Cleaning procedure:

  1. Shut down laptop completely
  2. Unplug power cable
  3. Dampen microfiber cloth with alcohol (not dripping wet!)
  4. Wipe touchpad surface in circular motions
  5. Clean edges and corners with cotton swab
  6. Pay attention to:
    • Oils from fingers
    • Dust and debris around edges
    • Sticky residue
  7. Let alcohol evaporate (1-2 minutes)
  8. Power on and test

Why cleaning helps:

  • Finger oils create uneven surface → cursor jumps
  • Dust/crumbs interfere with capacitive sensing
  • Clean touchpad = more accurate tracking
⚠️ Don't use: Glass cleaner (Windex), bleach, or harsh chemicals. Can damage touchpad coating. Stick to isopropyl alcohol 70%+ only.

13 Test for Hardware Damage Diagnostic

When to try: All software fixes failed, or touchpad physically damaged.

Signs of hardware failure:

  • Touchpad never detected (not in Device Manager, BIOS shows enabled)
  • Physical damage visible (cracks, dents, scratches)
  • Liquid spill on touchpad area
  • Touchpad surface bulging or uneven
  • Click buttons physically broken or stuck
  • Partial touchpad dead (top half works, bottom doesn't)

Test touchpad hardware:

  1. Boot from USB/Live Linux:
    • Create Ubuntu Live USB
    • Boot laptop from USB
    • Test touchpad in Linux environment
    • If works in Linux but not Windows → Windows driver issue
    • If doesn't work in Linux either → Hardware failure
  2. Check BIOS:
    • Enter BIOS setup
    • Try using touchpad in BIOS menus
    • If works in BIOS → Windows issue
    • If doesn't work in BIOS → Hardware problem

Common hardware failures:

  • Ribbon cable disconnected: Internal cable from touchpad to motherboard loose (fixable if comfortable opening laptop)
  • Touchpad controller failed: Chip on touchpad PCB dead (requires touchpad replacement)
  • Liquid damage: Corrosion from spills (may be repairable if caught early)
  • Physical trauma: Laptop dropped, pressure on touchpad (touchpad cracked)

14 Hardware Repair / Replacement Varies

When needed: Hardware failure confirmed, touchpad physically broken, or all troubleshooting failed.

Touchpad replacement cost:

  • Professional repair: $100-250 (parts + labor)
    • Parts: $30-80 (replacement touchpad)
    • Labor: $70-170 (1-2 hours)
  • DIY repair: $30-80 (parts only)
    • Difficulty: Medium-high
    • Requires: Opening laptop, disconnecting ribbon cables
    • Risk: Can damage other components if not careful

Warranty coverage:

  • Under warranty (1 year): Free repair if defect, not accidental damage
  • Extended warranty/protection plan: May cover accidental damage
  • Out of warranty: Full repair cost applies

DIY touchpad replacement steps (advanced):

  1. Identify exact laptop model
  2. Buy replacement touchpad (eBay, AliExpress, laptop parts sites)
  3. Find disassembly guide (YouTube: "[laptop model] touchpad replacement")
  4. Tools needed:
    • Phillips screwdriver (small)
    • Plastic pry tools
    • Tweezers
  5. General process:
    • Remove battery (if removable)
    • Remove bottom panel
    • Disconnect touchpad ribbon cable from motherboard
    • Remove screws holding touchpad
    • Install new touchpad
    • Reconnect ribbon cable carefully
    • Reassemble
  6. ⚠️ Ribbon cables VERY fragile - break easily

Alternative: Use external mouse permanently:

  • If repair cost too high ($200+) on old laptop ($300-500 value)
  • Wireless mouse: $15-40 (works as well as touchpad)
  • Trackball mouse: $30-80 (stationary, don't need desk space)
  • Portable mouse: Small USB mouse for travel
  • Much cheaper than touchpad repair

Repair vs Replace decision:

  • Repair if:
    • Laptop less than 3 years old
    • Under warranty (free repair)
    • High-end laptop ($1000+)
    • Repair cost under $150
  • Use external mouse if:
    • Laptop 4+ years old
    • Repair cost over $200
    • Budget laptop ($300-500 value)
    • Multiple hardware issues

Prevention & Best Practices

1. Avoid Accidental Disabling

  • Learn your touchpad hotkey: Know Fn+F? disables touchpad
  • Be careful gaming: Easy to accidentally press Fn keys
  • Disable hotkey if possible: Some laptops allow disabling touchpad toggle in BIOS

2. Keep Touchpad Clean

  • Weekly wipe: Microfiber cloth, dry or slightly damp
  • Monthly deep clean: Isopropyl alcohol wipe
  • Wash hands before use: Reduces oil buildup
  • Don't eat over laptop: Crumbs get under touchpad

3. Driver Maintenance

  • After Windows updates: Check touchpad still works, reinstall manufacturer driver if needed
  • Keep manufacturer drivers updated: Check laptop support page every 6 months
  • Backup working driver: When touchpad works perfectly, export driver (Device Manager → Properties → Driver → Driver Details → copy files)

4. Physical Care

  • Don't press too hard: Touchpads are capacitive, don't need pressure
  • Keep laptop dry: Liquid spills = touchpad death sentence
  • Avoid impact: Don't drop laptop or put heavy objects on it
  • Use palm rest correctly: Don't rest full weight on touchpad area

5. External Mouse as Backup

  • Always carry USB mouse when traveling: Touchpad fails = can still use laptop
  • Bluetooth mouse for regular use: Saves touchpad wear and tear
  • Test both regularly: Make sure both touchpad and mouse work

Common Questions

Q: My touchpad works but two-finger scroll doesn't. How to fix?

A: Settings → Touchpad → Enable "Scroll and zoom" gestures. If option greyed out: Your touchpad might not support multi-touch (old laptop, legacy touchpad). Check Device Manager - if says "HID-compliant mouse" instead of "Precision Touchpad", you don't have gesture support. Only solution: External mouse or upgrade laptop.

Q: Touchpad cursor jumps around while I'm typing. How to stop this?

A: Palm rejection issue. Solutions: (1) Lower touchpad sensitivity (Settings → Touchpad → "Low sensitivity"), (2) Enable typing delay (Synaptics software → Settings → Delay 1-2 seconds), (3) Raise wrists while typing (don't rest palms on touchpad area), (4) Use external keyboard if typing a lot.

Q: Can I disable touchpad permanently and only use external mouse?

A: Yes. Three methods: (1) Fn+F7 to disable (resets on restart), (2) Settings → Touchpad → Toggle OFF, (3) Device Manager → Right-click touchpad → Disable (permanent until re-enabled). Recommendation: Keep enabled as backup in case mouse fails.

Q: My Dell/HP/Lenovo touchpad stopped working after BIOS update. Fix?

A: BIOS updates sometimes reset settings. Enter BIOS → Find "Internal Pointing Device" or "Touchpad" → Make sure "Enabled". Save and exit. If still doesn't work: Reinstall touchpad driver from manufacturer website.

Q: Touchpad works in Safe Mode but not normal Windows. Why?

A: Driver or software conflict. Safe Mode uses basic drivers. Solution: Boot normal Windows, uninstall touchpad driver completely (Device Manager → Uninstall), restart, let Windows reinstall fresh driver. Or: Clean boot to identify conflicting software.

Q: Can I replace touchpad with different model/brand?

A: No. Touchpads are laptop-specific (different sizes, mounting points, ribbon cable connectors). Must use exact replacement part for your laptop model. Find on eBay/AliExpress by searching "[laptop model] touchpad replacement part".

Q: My touchpad click buttons are broken but tap-to-click works. Do I need repair?

A: No. Use tap-to-click permanently. Enable in Settings → Touchpad → Tap to click. Works just as well as physical clicking. Save $100-200 repair cost. Only repair if tap-to-click also doesn't work.

Q: Why does my touchpad randomly stop working for few seconds then start again?

A: Intermittent hardware failure. Usually: (1) Loose ribbon cable inside laptop (fixable by reseating cable), (2) Touchpad controller overheating (give laptop more ventilation), (3) USB controller glitching (update chipset drivers). If frequent (10+ times/day): Hardware dying, plan for replacement or external mouse.

Q: Does Windows 11 support all touchpad gestures from Windows 10?

A: Yes, plus more. Windows 11 adds extra gestures (four-finger tap, edge swipes). But only if you have Precision Touchpad. Legacy touchpads (Synaptics/ELAN) have same gestures as Windows 10. To check: Settings → Touchpad → If you see full gesture options = Precision Touchpad. If basic options only = Legacy.

Q: My MacBook trackpad not clicking anymore. How to fix?

A: MacBooks use Force Touch (haptic feedback, not physical click). If not clicking: (1) Trackpad → Tap to click → Enable (Settings → Trackpad), (2) Adjust click pressure (Settings → Trackpad → Force Click), (3) SMC reset (shut down, Shift+Control+Option+Power for 10 sec), (4) If Force Touch motor failed: $200-400 repair at Apple. Workaround: Enable tap-to-click.
