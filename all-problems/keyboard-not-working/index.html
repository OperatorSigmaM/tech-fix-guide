Keyboard Not Working? 13 Ways to Fix Laptop Keyboard

📅 Updated: January 2025 ⏱️ 14 min read Easy to Medium

🎯 Quick Summary

Main causes: Debris/liquid (30%), driver issue (25%), Filter Keys enabled (15%), hardware damage (15%), connection loose (10%), software conflict (5%)

Quick fixes: Restart laptop, disable Filter Keys, update keyboard driver, clean keyboard, reconnect cable (if removable)

Success rate: 70% fixable with software solutions, 25% need cleaning, 5% require keyboard replacement

First: Diagnose the Type of Keyboard Problem

Different symptoms = different fixes:

🔴 Entire keyboard not working:

  • No keys respond at all
  • Causes: Driver issue, keyboard disabled in settings, hardware connection
  • Quick test: Does on-screen keyboard work? If yes = physical keyboard issue

🔴 Some keys work, some don't:

  • Specific keys dead (often in a row or column)
  • Causes: Debris under keys, liquid damage, physical damage to keyboard matrix

🔴 Keys typing wrong letters:

  • Press A, get Q or numbers instead of letters
  • Causes: Wrong keyboard layout selected, Num Lock on (laptop), stuck modifier key

🔴 Keys repeating continuously:

  • Single keypress types multiple characters: "heeeeelllllo"
  • Causes: Sticky Keys enabled, debris, key physically stuck

🔴 Intermittent - works sometimes:

  • Keyboard stops randomly, works after restart
  • Causes: Driver conflict, loose connection, overheating
💡 Quick diagnostic:
1. Plug in USB keyboard - works? = Laptop keyboard is the problem, not drivers/software
2. Boot into BIOS (F2/Del) - keyboard works there? = Windows driver issue
3. Use On-Screen Keyboard (Windows + Ctrl + O) to access settings while troubleshooting

Quick Software Fixes to Try First

1 Restart Laptop Success: 25%

Why it works: Resets keyboard drivers, clears temporary glitches, releases stuck software states.

Proper restart:

  1. Close all programs
  2. Click Start → Power → Restart (NOT sleep or shutdown)
  3. Wait for full reboot
  4. Test keyboard immediately after login

If can't use keyboard to restart:

  1. Press Ctrl+Alt+Del (might still work)
  2. OR Click power icon in bottom right corner with mouse
  3. OR Hold physical power button 10 seconds to force shutdown, then power on

2 Disable Filter Keys Success: 20%

Why it works: Filter Keys is accessibility feature that ignores brief keystrokes. Often enabled accidentally by pressing Shift 5 times.

Windows 10/11:

  1. Settings (Windows + I or click Start → gear icon)
  2. Ease of Access (or Accessibility)
  3. Keyboard
  4. Turn OFF "Filter Keys"
  5. Also turn OFF "Sticky Keys" and "Toggle Keys" while here

Quick disable:

  1. Press and hold Right Shift for 8 seconds
  2. Dialog box appears asking to enable/disable Filter Keys
  3. Click "No" or press Esc
✓ Prevent accidental activation: In Filter Keys settings, uncheck "Allow the shortcut key to start Filter Keys" so Shift x5 doesn't trigger it.

3 Check Keyboard Layout/Language Success: 10%

Why it matters: Wrong keyboard layout makes keys type different letters (QWERTY vs AZERTY, etc.)

Check current layout:

  1. Look at taskbar (bottom right) - language indicator (e.g., "ENG", "FRA")
  2. Click it to see available keyboards
  3. Make sure correct one selected (usually English US or your region)

Change keyboard layout:

  1. Settings → Time & Language → Language
  2. Click your language → Options
  3. Under Keyboards, remove unwanted layouts
  4. Add correct layout if missing

Quick shortcut to switch:

  • Windows + Space - cycles through installed keyboard layouts
  • Alt + Shift - also switches layouts (can be disabled in settings)

4 Turn Off Num Lock Success: 15%

Why it matters: On some laptops, Num Lock turns part of keyboard into number pad (J/K/L become 1/2/3, etc.)

Check if Num Lock is on:

  • Look for Num Lock indicator light on keyboard
  • Try typing - do letters produce numbers?

Disable Num Lock:

  • Press Num Lock key (sometimes labeled "Num Lk")
  • On some laptops: Fn + Num Lock
  • Common locations: F11, F12, or Insert key with Num Lock icon
💡 Mac users: Num Lock issues are rare on Mac. If experiencing wrong characters, check keyboard layout in System Preferences → Keyboard → Input Sources.

5 Update Keyboard Driver Success: 20%

Why it works: Corrupted or outdated keyboard driver causes malfunction.

Update via Device Manager:

  1. Right-click Start → Device Manager
  2. Expand "Keyboards"
  3. Right-click your keyboard (usually "Standard PS/2 Keyboard" or "HID Keyboard Device")
  4. Select "Update driver"
  5. Choose "Search automatically for drivers"
  6. Restart after update

Reinstall driver:

  1. Device Manager → Keyboards
  2. Right-click keyboard → Uninstall device
  3. Check "Delete the driver software for this device" if option appears
  4. Click Uninstall
  5. Restart laptop (Windows will reinstall driver automatically)
⚠️ After uninstalling: Keyboard won't work until restart. Use mouse to navigate to Restart. Or use on-screen keyboard (search "osk" in Start menu).

6 Run Keyboard Troubleshooter (Windows) Success: 10%

Why it helps: Automatically detects and fixes common keyboard issues.

Windows 10/11:

  1. Settings → Update & Security → Troubleshoot
  2. Additional troubleshooters
  3. Keyboard → Run the troubleshooter
  4. Follow prompts
  5. Apply recommended fixes
  6. Restart and test

7 Disable Fast Startup Success: 10%

Why it works: Fast Startup can prevent keyboard from initializing properly on boot.

Disable:

  1. Control Panel → Power Options
  2. Choose what the power buttons do (left sidebar)
  3. Change settings that are currently unavailable
  4. Uncheck "Turn on fast startup"
  5. Save changes
  6. Restart

Cleaning Solutions for Physical Issues

8 Clean Keyboard with Compressed Air Success: 20%

Why it works: Dust, crumbs, hair under keys prevent proper contact.

Safe cleaning method:

  1. Shut down laptop and unplug
  2. Tilt laptop at 75-degree angle (almost upright)
  3. Use compressed air can (hold upright, short bursts)
  4. Spray between keys from left to right, row by row
  5. Rotate laptop and spray from different angles
  6. Tap bottom gently to dislodge debris
  7. Wait 5 minutes before powering on

What you might see come out:

  • Dust bunnies
  • Food crumbs
  • Pet hair
  • Lint from pockets/bags
⚠️ Don't:
• Shake compressed air can (sprays liquid)
• Hold can upside down
• Use vacuum (creates static, can damage components)
• Use too much force (can damage key switches)

9 Remove and Clean Individual Keys Success: 25%

When to try: Specific keys not working, sticky keys, visible debris under key.

⚠️ Risk level: Medium - can break key clips if not careful!

Safe key removal (for most laptops):

  1. Shut down and unplug laptop
  2. Take photo of keyboard first (remember key positions)
  3. Use plastic pry tool or flat butter knife (NOT screwdriver)
  4. Gently pry from TOP edge of key
  5. Lift slowly - should pop off with minimal force
  6. Note: Small plastic hinges underneath - DON'T LOSE THEM

Clean under key:

  1. Wipe rubber membrane with slightly damp cloth
  2. Clean keycap with isopropyl alcohol
  3. Let dry completely (5 minutes)
  4. Reattach key: Align hinges, press down until click
🚨 DO NOT REMOVE on these laptops:
• MacBook (2016-2020 Butterfly keyboard) - keys extremely fragile
• Many ultrabooks with low-profile keyboards
• If unsure, DON'T RISK IT - use compressed air only

MacBook keyboard cleaning (no removal):

  1. Tilt Mac at 75 degrees
  2. Compressed air in left-to-right motion
  3. Rotate and repeat from other angle
  4. Apple's official method for Butterfly keyboards

10 Fix Liquid Damage Success: Variable

If you spilled liquid on keyboard:

IMMEDIATE actions (first 60 seconds critical):

  1. Power off IMMEDIATELY (hold power button, don't shutdown normally)
  2. Unplug AC adapter
  3. Flip laptop upside down immediately (prevents liquid reaching motherboard)
  4. Remove battery if possible
  5. Tilt keyboard-side down and shake gently

Drying process:

  1. Keep laptop upside down in tent position (⌃ shape)
  2. Place in front of fan (not heater - heat damages components)
  3. Leave for 48-72 hours minimum
  4. Do NOT turn on before fully dry
  5. Do NOT use rice (ineffective, leaves dust)

After drying:

  1. If water only: Might work after drying
  2. If sugary drink (soda, juice): Sticky residue remains, needs cleaning
  3. If coffee/alcohol: Corrosive, likely needs keyboard replacement

Professional cleaning (if DIY doesn't work):

  • Repair shop can disassemble and clean with isopropyl alcohol
  • Cost: $50-100 for cleaning
  • If keyboard still dead after cleaning: needs replacement
🚨 NEVER do after spill:
• Try to turn on to "see if it works"
• Use hair dryer on high heat
• Put in oven/microwave (yes, people try this)
• Wait "just a few hours" - needs 2-3 DAYS minimum

Hardware Fixes & Troubleshooting

11 Reconnect Keyboard Cable (Advanced) Success: 15%

When to try: Entire keyboard not working after trying all software fixes. Laptop was dropped or opened recently.

⚠️ Difficulty: Medium-Hard. Only attempt if comfortable opening laptop.

Procedure (varies by laptop):

  1. Look up disassembly guide for your exact laptop model (iFixit, YouTube)
  2. Shut down, unplug, remove battery
  3. Remove bottom panel (usually 10-15 screws)
  4. Locate keyboard ribbon cable (flat cable connecting keyboard to motherboard)
  5. Carefully disconnect ribbon cable (flip up locking tab, pull cable straight out)
  6. Inspect cable for damage (tears, kinks)
  7. Reconnect firmly - should slide in easily and feel secure
  8. Lock cable (flip tab down)
  9. Reassemble and test
⚠️ Risks:
• Voids warranty
• Can damage ribbon cable if too forceful
• Static discharge can damage motherboard
• Only try if warranty expired or comfortable with risk

12 Replace Keyboard Cost: $30-150

When keyboard replacement needed:

  • Multiple keys permanently dead after all fixes
  • Physical damage (cracked keys, broken mounting)
  • Liquid damage that cleaning didn't fix
  • Keys physically falling off

Replacement options:

Option 1 - DIY Replacement:

  • Difficulty: Medium (varies by laptop model)
  • Cost: $30-60 for keyboard, $10-20 for tools
  • Time: 1-2 hours
  • Best for: Older laptops, budget laptops, if you're tech-savvy

DIY steps:

  1. Buy replacement keyboard (eBay, Amazon, manufacturer parts site)
  2. Watch full disassembly video for your exact model
  3. Follow guide carefully
  4. Common steps: Remove bezel, unscrew keyboard, disconnect cable, reverse to install

Option 2 - Professional Replacement:

  • Cost: $80-150 (parts + labor)
  • Time: 1-3 days
  • Best for: Newer laptops, warranty still active, not comfortable with DIY

Option 3 - Manufacturer Service:

  • Cost: $150-250
  • Best for: Under warranty, premium laptops (MacBook, XPS, etc.)

Where to buy keyboards:

  • Manufacturer parts store: Most expensive but guaranteed fit
  • eBay: Cheapest, verify seller rating and compatibility
  • Amazon: Good return policy if doesn't fit
  • Laptop Parts Outlet: Specialized retailers, good quality
💡 Check compatibility: Need EXACT model number. Same series (e.g., Dell Inspiron 15) might have different keyboards. Check laptop bottom sticker for full model number.

13 Use External Keyboard (Workaround) Cost: $15-100

When to use: Temporary solution while waiting for repair, or if repair not worth cost.

External keyboard options:

  • USB wired keyboard: $15-40, most reliable, no batteries needed
  • Bluetooth keyboard: $25-80, wireless convenience, needs charging
  • Portable folding keyboard: $40-70, great for travel

Setup:

  1. Plug in USB keyboard (works immediately, no setup)
  2. OR pair Bluetooth keyboard (Settings → Bluetooth → Add device)
  3. Laptop keyboard and external can both work simultaneously

Disable built-in keyboard (optional):

  1. Device Manager → Keyboards
  2. Right-click laptop keyboard → Disable device
  3. Prevents accidental key presses from broken built-in keyboard

Recommended keyboards:

  • Budget: Logitech K120 ($15-20)
  • Mid-range: Logitech K380 Bluetooth ($30-40)
  • Premium: Keychron K2 ($70-90)
  • Portable: iClever Foldable ($35-45)

How to Prevent Keyboard Problems

1. Keep Keyboard Clean

  • Monthly compressed air cleaning: Prevents debris buildup
  • Don't eat over keyboard: Crumbs are #1 cause of sticky keys
  • Wash hands before use: Reduces oil and dirt transfer
  • Use keyboard cover: Silicone covers protect from dust (but reduce typing feel)

2. Liquid Protection

  • No drinks near laptop: Spills happen in seconds
  • Use spill-proof containers: Travel mugs with lids if you must
  • Keep drinks below keyboard level: Physics - liquid won't jump up
  • Work on stable surface: Avoid beds, couches where drinks can tip

3. Gentle Usage

  • Don't pound keys: Normal typing pressure sufficient
  • No prying at keys: Unless absolutely necessary for cleaning
  • Close lid gently: Slamming can loosen keyboard connections
  • Transport safely: Don't stack heavy items on closed laptop

4. Software Maintenance

  • Keep drivers updated: Windows Update usually handles this
  • Disable Filter Keys shortcut: Prevents accidental activation
  • Regular restarts: Weekly restart prevents driver issues

Mac-Specific Keyboard Fixes

🍎 Reset NVRAM/PRAM

  1. Shut down Mac
  2. Power on, immediately hold: Command + Option + P + R
  3. Hold for 20 seconds (Mac may restart)
  4. Release keys, Mac boots normally

🍎 Reset SMC

MacBook (T2 chip, 2018-2020):

  1. Shut down
  2. Hold Shift + Control + Option (left side) + Power for 10 seconds
  3. Release all, power on

Apple Silicon (M1/M2/M3):

  1. Shut down
  2. Wait 30 seconds
  3. Power on (SMC resets automatically)

  3. Schedule repair at Apple Store or mail-in

Troubleshooting Specific Symptoms

Numbers instead of letters (e.g., JKL = 123):

  • Cause: Num Lock on
  • Fix: Press Fn + Num Lock (or just Num Lock)

@ symbol types " or other wrong symbol:

  • Cause: Wrong keyboard layout (US vs UK)
  • Fix: Settings → Language → Keyboard → Switch to correct layout

Keys working in BIOS but not Windows:

  • Cause: Driver issue
  • Fix: Reinstall keyboard driver in Device Manager

Keyboard works in Safe Mode but not normal boot:

  • Cause: Software conflict (possibly malware)
  • Fix: Uninstall recently installed programs, run antivirus scan

When to Replace vs Repair Laptop

✓ Worth repairing keyboard if:

  • Laptop is under 3 years old
  • Mid-range to high-end laptop ($600+)
  • Only issue is keyboard (everything else works great)
  • Repair/replacement cost under $150
  • Under warranty or covered by repair program

⚠️ Consider buying new laptop if:

  • Laptop is 5+ years old
  • Budget laptop (under $400 original)
  • Multiple issues (slow, battery dead, screen problems)
  • Repair cost exceeds 50% of replacement cost
  • Can use external keyboard comfortably (saves $150)

Common Questions

Q: Why does my keyboard work in BIOS but not Windows?

A: BIOS uses basic keyboard drivers that always work. Windows uses advanced drivers that can get corrupted. Reinstall keyboard driver in Device Manager.

Q: Only some keys don't work. Is keyboard broken?

A: Not necessarily. Try compressed air cleaning first. Often debris under specific keys. If still broken after cleaning, keyboard matrix might be damaged (needs replacement).

Q: Can I replace just one key or do I need whole keyboard?

A: Individual keycaps can be bought on eBay/Amazon for $2-5. But if key mechanism broken, need whole keyboard. Keycaps are cheap to try first.

Q: My keys feel mushy/sticky but still work. How to clean?

A: Compressed air first. If still sticky, remove keycaps one by one and clean with isopropyl alcohol. Let dry completely before reinstalling.

Q: How much does keyboard replacement cost?

A: DIY: $30-60 for keyboard. Professional: $80-150 including labor. Manufacturer service: $150-250. MacBook Butterfly keyboard: Free if covered by repair program.

Q: Keyboard stopped working after Windows update. What to do?

A: Common issue. Uninstall recent update (Settings → Update History → Uninstall updates) or reinstall keyboard driver. Problem usually fixed in next update within a week.

Q: Can a virus disable my keyboard?

A: Yes, though rare. Boot into Safe Mode - if keyboard works there but not normally, run antivirus scan. Malwarebytes recommended.
